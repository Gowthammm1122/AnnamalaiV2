# 🎓 Dr. P. Annamalai IAS Academy

> Shaping future leaders, mentored by experts.

A premium, state-of-the-art web application developed to showcase the curriculum, academic features, and success stories of **Dr. P. Annamalai IAS Academy**—a premier coaching institute for UPSC Civil Services and State Public Service Commission (TNPSC) examinations.

---

## 💻 About the Project

This website provides a modern, fast, and responsive digital experience for students, aspirants, and parents. It highlights:
- **Comprehensive Course Outlines**: Dedicated spaces detailing curriculum structures for UPSC IAS, IPS, IFS, and Central/State Services.
- **Academy Training Features**: Diagnostics tests details, active writing evaluation panel, and mock interview guidelines by senior retired bureaucrats.
- **Dynamic Design**: Tailored visual animations, responsive elements, and interactive modals for high-fidelity engagement.
